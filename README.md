# DalamudPlugins

个人维护的 Dalamud 插件仓库

## 仓库地址

```
https://raw.githubusercontent.com/RoefQwQ/DalamudPlugins/main/pluginmaster.json
```

## 包含插件

### InventoryTools (中文版)

FF14 库存管理插件的中文汉化版本，功能包括：
- 背包管理
- 物品筛选
- 制作列表
- 市场板价格追踪
- 装备推荐

## 使用方法

1. 在 Dalamud 设置中添加上方仓库地址
2. 在插件安装器中搜索 "InventoryTools"
3. 安装并享受中文界面

## 源码

- 汉化版源码: https://github.com/RoefQwQ/InventoryTools
- 原版插件: https://github.com/Critical-Impact/InventoryTools
